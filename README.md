## 🧩 My Coding Standards

Every solution will aim to include:

- **Problem Statement:** A clear description of the problem.
- **Java Solution:** Readable, well-formatted code.
- **Logic:** A simple explanation of the approach.
- **Sample Output:** Demonstration of the result.
- **Complexity Analysis:** Time and space complexity when applicable.
- **Optimization:** A better approach wherever possible.
